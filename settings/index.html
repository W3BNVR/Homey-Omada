Homey.OmadaIntegration

Verbind deze Homey met je lokale Omada Software Controller.

Neem dit adres over uit Omada: Global View → Settings → Platform Integration → Open API → jouw app → View.

Maak in Omada een API-app in Client mode. Deze gegevens blijven nodig voor de Open API.

Nodig voor het ophalen en behouden van de huidige switchpoortinstellingen bij PoE-wijzigingen. Gebruik een lokaal controlleraccount met rechten om switchpoorten te wijzigen.

Schakel dit alleen in als je lokale controller een zelfondertekend HTTPS-certificaat gebruikt.
